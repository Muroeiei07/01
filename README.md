# 王清越 - 個人網頁 (Dark Theme Portfolio)

這個專案是為 **王清越 (Wang Qing-Yue)** 設計的深色主題 (Dark Theme) 個人網頁。
使用純 HTML5, CSS3 和 Vanilla JavaScript 開發，確保代碼乾淨、無毒且易於維護。

## 📁 檔案結構

*   `index.html`: 網頁主架構。
*   `style.css`: 網頁樣式 (深色主題)。
*   `script.js`: 互動功能 (打字機效果、滾動動畫、背景特效)。
*   `README.md`: 本說明檔。

## 🚀 如何使用與部署

1.  **準備大頭貼**: 請準備一張您的照片，命名為 `profile.jpg`，並放在與 `index.html` 相同的資料夾中。
2.  **本地預覽**: 雙擊打開 `index.html` 即可在瀏覽器中預覽。
3.  **部署到 Vercel**: 
    *   登入 [Vercel](https://vercel.com/)。
    *   選擇 "Add New Project"，將包含這四個檔案的資料夾拖曳上傳即可。
4.  **部署到 GitHub Pages**:
    *   將這四個檔案上傳到您的 GitHub Repository。
    *   進入 Settings > Pages，將 Source 設定為 `main` 分支並儲存。
